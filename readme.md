Template de artigo da Sociedade Brasileira de Computação em Typst, sendo feito com muito amor ao jogo e pouco amor ao LaTeX.

Ainda sem preview. Vou colocar uma assim que estiver apresentável.

**Para baixar e tornar acessível localmente:**

```bash
mkdir ~/.local/share/typst/packages/local/brazilian-computer-society
git clone "https://github.com/seruna-1/typst-sbc.git" ~/.local/share/typst/packages/local/brazilian-computer-society/0.1.0
```

**Para iniciar a partir do modelo:**

```bash
typst init @local/brazilian-computer-society:0.1.0 artigo-para-entregar-amanha
```
